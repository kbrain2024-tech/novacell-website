# NovaCell v33 공식 홈페이지 이미지 교체 패치

이 패치는 `novacell.kr` 공식 홈페이지의 이미지 두 장만 교체합니다.

## 교체 파일

- `images/reflex-guide-main-gate-v2.png`
  - 리플렉스 테라피 가이드 대표 이미지
- `images/healing-points-main.jpg`
  - Healing Points 대표 이미지

## 적용 방법

1. 이 압축파일을 풉니다.
2. 압축을 푼 폴더 안의 `images` 폴더를 NovaCell 홈페이지 GitHub 저장소 최상위 위치에 업로드합니다.
3. GitHub에서 위 두 파일의 교체를 확인합니다.
4. Netlify 자동 배포가 끝난 뒤 `https://novacell.kr/ko/index.html`에서 확인합니다.

## 변경하지 않는 항목

- HTML과 CSS
- 한국어·영어 전환
- 로그인·회원가입
- 상품 가격과 문구
- 메뉴와 링크
- `guide.novacell.kr`
- `healing.novacell.kr`

기존 정상 기능을 보존하기 위해 공식 홈페이지의 두 이미지 파일 이외에는 포함하지 않았습니다.
