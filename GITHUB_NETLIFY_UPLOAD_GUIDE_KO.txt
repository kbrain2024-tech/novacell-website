GitHub와 Netlify 배포 순서

1. 이 ZIP 파일을 컴퓨터에서 압축 해제합니다.
2. 압축을 푼 폴더 안의 모든 파일과 폴더를 GitHub 저장소의 최상위 위치에 올립니다.
3. GitHub 화면에서 index.html, en, images, css, js 폴더가 같은 화면에 보이는지 확인합니다.
4. Netlify에서 GitHub 저장소를 연결합니다.
5. Build command는 비워 둡니다.
6. Publish directory도 비워 둡니다. (기본값: 저장소 최상위)
7. Deploy site를 누릅니다.

검사 기준
- Netlify 첫 화면에 NovaCell 기기 이미지가 보여야 합니다.
- 상단 메뉴와 첫 화면 중간에 NovaCell Reflex Therapy Guide 안내가 보여야 합니다.
- /en/reflex-guide.html 주소에서 1-Year Pass 정보를 볼 수 있어야 합니다.

회원가입과 테스트 결제는 이 화면 확인이 끝난 다음 단계에서 연결합니다.
